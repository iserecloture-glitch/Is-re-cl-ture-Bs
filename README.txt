# Site internet Isère Clôture

Ce dossier contient un site vitrine simple pour l'entreprise Isère Clôture.

## Fichiers
- index.html : page principale du site
- style.css : design du site

## À compléter
Dans la section Contact, remplacez :
- Téléphone : à compléter
- Email : à compléter

Ajoutez aussi vos vraies photos de chantiers dans la section Réalisations.

## Mise en ligne
Vous pouvez envoyer ces fichiers chez un hébergeur comme OVH, IONOS, o2switch, Hostinger ou Netlify.
